# Changelog
# Little Legends: Endless World

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-10-14
### Added
- Project initialization with Vite, React 18, TypeScript (strict mode), Tailwind CSS, Phaser 3, and Dexie.js.
- Complete documentation suite (GDD, Architecture, Roadmap, Asset Guide, Save Format, Testing, Deployment).
- Decoupled domain simulation architecture for testable combat, inventory, and procedural generation.
- Responsive bilingual (Thai/English) localization infrastructure.
